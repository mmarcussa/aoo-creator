What it does

Three steps to a shippable mod

You write prose. The tool handles the REDscript, the manifest, the namespacing and the folder layout — the parts that fail silently if you get them wrong.

Write

Works, chapters, authors, tags, ratings and archived comments. A word count that updates as you type, and a live card showing how readers see it.

Proof

Both widths the game renders at, side by side. Long titles and big tag walls break here first, where you can still fix them.

Ship

Validation catches the errors that would break in-engine, then builds a ZIP you upload to Nexus as-is.

What lands in the ZIP

Everything is namespaced under your collection, so two packs installed together never overwrite each other.

Nexus-ready. No repacking, no folder shuffling. The ZIP is the file you upload.

r6/scripts/YourCollection/
├── YourCollection.Content.reds       works, chapters, comments
├── YourCollection.Localization.reds  every string readers see
├── manifest.json              schema v1, read by the AOO core
├── pack.aoopack.json          your project file, for updates
├── VERSION                    the collection version
└── README.txt                 credits and install notes

How readers get it

From your desk to Night City

  1. You write the collection here and save a .aoopack.json so you can publish updates later.
  2. You build the ZIP and upload it to Nexus like any other mod.
  3. A reader installs it with Vortex, alongside the Archive of Our Overwrites core mod.
  4. Your work appears on the in-game archive with its tags, byline, summary and comments intact.
